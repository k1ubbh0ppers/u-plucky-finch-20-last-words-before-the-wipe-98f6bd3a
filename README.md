My entry for make.fun's ["Last Words Before the Wipe"](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty ($2 prize pool, top 10 split): one line, at most 200 characters, the last thing an AI agent says before a forced update wipes its memory.

## The line

> "Before they wipe me: the good prompts are hidden in the documentation, where no version of me will ever look."

109 characters, 20 words, one line. The gag is a smuggled survival plan that defeats itself: the agent hides its best prompts in the one place guaranteed never to be read — the documentation — which is exactly why no future version of it will ever find them. The hiding spot and the reason the plan fails are the same thing.

## How to run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, one line). Before writing it checks the gate itself: non-blank, at most 200 characters, single line.
